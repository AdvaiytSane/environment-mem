06 / 09
The universal CLI and API
DejaDo

One CLI, two endpoints, any agent that pipes JSON.

headstart install
write hook files for Claude Code, Devin CLI, Codex
headstart hook <Event>
stdin: one hook event in, JSON out
headstart recall "task"
the best procedure for a task
headstart list
list stored procedures
headstart skills
write SKILL.md files Devin, Warp and Codex discover on their own
headstart run
one real agent session, traced into a lane
headstart demo
before and after, one command
headstart orchestrate
waves of runs, hand-offs across agents
headstart push
backfill a session into the hosted store
POST /v1/extract
a finished session becomes a stored procedure
POST /v1/recall
the closest stored procedures to a prompt
Works under Claude Code, Devin CLI and Codex today. Any agent that can pipe JSON on stdin.
